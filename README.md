# VelhoEscola

Versão corrigida para GitHub Pages.

## Estrutura
- `index.html`
- `css/style.css`
- `js/script.js`

## Conexões
O HTML usa caminhos relativos:
- `./css/style.css`
- `./js/script.js`

## Publicação
No GitHub, envie os três arquivos mantendo exatamente as pastas `css` e `js`.
Depois ative GitHub Pages em Settings > Pages > Deploy from branch.

O progresso é salvo no `localStorage` do navegador.
